# MITHILA - Traditional Thekua Ecommerce

MITHILA is a modern single-vendor ecommerce website focused on traditional Mithila Thekua, curated collections, gifting, customer experience, and online ordering.

The project combines a premium traditional-inspired frontend with backend services, database management, authentication, product management, shopping cart, orders, customer accounts, reviews, wishlist, and seller dashboard functionality.

---

- Built with Next.js and React
- JavaScript-based application
- Tailwind CSS for responsive UI
